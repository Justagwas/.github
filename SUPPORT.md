# Support

Help is available through the issue tracker of the affected repository.

## Before requesting help

1. Read the project's README and documentation.
2. Check its installation, compatibility, and troubleshooting guidance.
3. Search existing issues for the same behavior.
4. Confirm that the problem still occurs with the latest supported release or default branch.

## What to include

Provide the information needed to understand the request:

- Project version or commit.
- Operating environment, device, or service involved.
- Relevant settings or configuration.
- Exact steps leading to the behavior.
- Expected and observed results.
- Logs, screenshots, or minimal examples when useful.

Remove credentials, access tokens, personal information, private URLs, and unrelated data before posting.

## Scope

Support is provided on a best-effort basis. Response times are not guaranteed, and support may be limited for unsupported versions, modified builds, environments outside the documented scope, or third-party services.

## Security reports

Do not report vulnerabilities publicly. Follow the shared [Security Policy](https://github.com/Justagwas/.github/blob/main/SECURITY.md).
