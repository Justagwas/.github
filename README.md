# Justagwas community health files

This repository contains the shared contribution and support policies used across public repositories maintained by Justagwas.

GitHub applies these files to a public repository when that repository does not provide its own version. A project may retain a local file when its development process, safety requirements, support information, or issue diagnostics require more specific guidance.

## Shared files

- `CODE_OF_CONDUCT.md` defines the standards for community participation.
- `CONTRIBUTING.md` provides the baseline contribution process.
- `SECURITY.md` explains how to report vulnerabilities privately.
- `SUPPORT.md` explains where and how to request help.
- `FUNDING.yml` configures the GitHub Sponsors link.
- `PULL_REQUEST_TEMPLATE.md` provides a concise review checklist.
- `.github/ISSUE_TEMPLATE/` provides baseline forms for bugs, proposals, and questions.

## Repository-specific files

Licenses, ownership rules, workflows, release configuration, privacy notices, end-user terms, and specialized development instructions remain in their respective repositories.

Project-specific files take precedence over the defaults defined here.
